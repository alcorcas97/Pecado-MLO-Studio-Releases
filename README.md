# Pecado MLO Studio Releases

Repositorio público utilizado exclusivamente para distribuir instaladores y metadatos de actualización automática de Pecado MLO Studio.

Los archivos de código fuente permanecen en el repositorio privado principal. Este repositorio contiene únicamente publicaciones de versión necesarias para que `electron-updater` pueda comprobar y descargar actualizaciones sin exponer credenciales privadas.
